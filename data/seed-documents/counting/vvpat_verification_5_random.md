# VVPAT Verification — 5 Random Polling Stations

## Supreme Court Mandate (2019)
- Prior to 2019: Only 1 polling station per constituency was VVPAT-verified
- April 2019: Supreme Court increased to **5 polling stations per Assembly constituency**
- Applies to all elections: Lok Sabha, State Assembly, and by-elections

## Selection Process
1. Lottery draw conducted at counting center before counting begins
2. Returning Officer draws 5 polling station numbers randomly
3. All candidates and agents witness the draw
4. Selected station numbers announced publicly

## Verification Process
1. VVPAT units from selected stations brought to designated counting table
2. VVPAT compartment opened **under videographic recording**
3. Each printed slip extracted one by one
4. Slips sorted candidate-wise and counted
5. VVPAT slip count compared with EVM display count for that station

## If Counts Match
- Result from that polling station accepted
- Verification certificate signed by all present
- Slips re-sealed and stored

## If Counts Don't Match
- **VVPAT count prevails** (as per Supreme Court direction)
- The discrepancy is recorded in writing
- Both EVM and VVPAT unit sealed for forensic examination
- Incident reported to ECI immediately
- Does not invalidate results from other polling stations
