# EVM Poll Day Protocols

## Pre-Poll Setup (5:00 AM - 7:00 AM)

### Booth Arrangement
1. EVM placed on table with Balloting Unit facing voter
2. Control Unit placed with Presiding Officer
3. VVPAT placed between voter and Control Unit for slip viewing
4. Voting compartment screened for secrecy

### Seal Verification
- Presiding Officer verifies all seal numbers against **Seal Register**
- Polling agents of candidates verify seals independently
- Any discrepancy recorded in **Form 17A** (Register of Voters)
- If seals are broken/tampered → machine replaced with reserve unit

## Mandatory Mock Poll

### Process (Rule 49MA)
1. **Minimum 50 votes** cast during mock poll (at least 1 per candidate)
2. Presiding Officer invites all polling agents to observe
3. Votes distributed across all candidates including NOTA
4. **VVPAT slips** collected and counted
5. Mock poll result compared with CU display result
6. If match: **Mock poll certificate** signed by all polling agents
7. If mismatch: Machine replaced and process repeated
8. After successful mock poll, **clear button** pressed to reset all counts to zero
9. Zero reading displayed and confirmed by all agents

## Voting Process (7:00 AM - 6:00 PM)

### Voter Flow
1. Voter identity verified (EPIC/approved ID)
2. Voter's finger checked for indelible ink
3. Indelible ink applied to left index finger
4. Entry recorded in **Form 17A**
5. Voter receives **ballot slip** from Presiding Officer
6. Presiding Officer presses **Ballot** button on Control Unit
7. Green light appears on Balloting Unit → voter can now press chosen button
8. VVPAT displays printed slip for **7 seconds** behind viewing window
9. Slip drops into sealed VVPAT compartment
10. Beep confirms successful vote recording

### Handling Exceptions
- **Tender vote** (Rule 49P): If someone has already voted in a person's name
- **Test vote** (Rule 49MA): If challenged by polling agent
- **Physically disabled voters**: Companion allowed (Rule 49N)
- **Machine malfunction**: Replace with reserve unit, continue polling

## Closing Procedures (6:00 PM or after last voter)

1. Presiding Officer announces **close of poll**
2. **Close** button pressed on Control Unit
3. Total votes cast displayed — verified against Form 17A entries
4. Control Unit sealed in carrying case with:
   - Green paper seal (signed by polling agents)
   - Strip/thread seal
   - Address tag
5. VVPAT sealed separately
6. All sealed units transported to **counting center strong room**
7. Strong room sealed with double locks
