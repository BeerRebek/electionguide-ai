# Indelible Ink
- Manufactured by Mysore Paints and Varnish Limited (sole authorized manufacturer)
- Contains silver nitrate — reacts with skin proteins
- Applied to the cuticle of the left forefinger nail
- Stains for 48-72 hours, preventing duplicate voting
- Cannot be easily removed with soap, acetone, or bleach

# Complaint Filing (Rule 49MA)
- If voter believes VVPAT slip shows wrong candidate, they report to Presiding Officer
- Presiding Officer conducts a test vote on the same machine
- If test vote is correct, no further action
- If test vote confirms error, that EVM/VVPAT is withdrawn and replaced
- Voter's original vote stands (recorded electronically on EVM)
