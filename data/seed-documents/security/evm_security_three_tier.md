# EVM Security — Three-Tier System

## Tier 1: Technical Safeguards
- OTP microcontroller — programmed once, cannot be reprogrammed
- No operating system, no Wi-Fi, Bluetooth, USB, or connectivity
- Software developed internally by BEL/ECIL engineers
- Each EVM has a unique ID number

## Tier 2: Administrative Safeguards
- Dual randomization: EVMs randomly assigned to constituencies, then to polling stations
- Strong rooms with 24/7 CRPF guard, CCTV, double lock, paper seals
- Chain of custody documentation at every stage

## Tier 3: Procedural Safeguards
- First Level Checking (FLC) with candidate representatives
- Mandatory 50-vote mock poll before actual polling
- Candidate agents present at every critical stage
- Pink paper seals on control unit result section
- VVPAT verification in 5 random stations per constituency

## NOTA
- Introduced 2013 following Supreme Court judgment in PUCL v. Union of India
- Allows voters to reject all candidates
- NOTA votes counted but do not affect the winning candidate determination

## cVIGIL App
- Citizens report violations with GPS-tagged photo/video evidence
- 100-minute response guarantee from flying squads
